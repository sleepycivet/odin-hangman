# odin-hangman

Whew! This was a tough project but I'm so glad that I did it. I feel like I really learned a lot.

I'm not sure why but beforehand, I really did not utilize hashes in my code. It's probably because I wasn't very comfortable using them or hadn't used them often. Through this project, I became much more comfortable with them.

And through my hash usage, I figured out how to use protected class variables so that they could only be changed or accessed via methods. Beforehand, I would expose them for testing purposes but I figured out how to structure the project and classes so that I could test the functionality without. This brings me closer to testing along the edge!

I also learned the magic of using 'subject' and 'before' in RSpec which gave me a bit more of a robust way to run code before running different tests on the result.

I was really unsure about files and serialization before starting the project but, after completion, I feel like this is such a cool thing to learn!
